# 🎓 CampusSync: Student Event Manager & Task Organizer



## 🚀 Overview
CampusSync is an all-in-one productivity platform designed specifically for students. Built during the [Insert Hackathon Name] hackathon, it tackles the chaos of university life by combining campus event discovery with a powerful, intuitive to-do list manager. Never miss a workshop, and never forget an assignment again.

## ✨ Features
*   **📊 Smart Dashboard**: Get a bird's-eye view of your day with summaries of upcoming campus events and pending academic tasks.
*   **📅 Campus Event Manager**: Browse curated upcoming events, workshops, and club meetings with location and timing details.
*   **✅ Advanced To-Do List**: 
    *   Add, edit, and delete tasks instantly.
    *   Mark tasks as complete to track your progress.
    *   Filter by Active and Completed tasks.
*   **🎨 Modern UI/UX**: A clean, responsive design built for both desktop and mobile viewing.

## 🛠️ Tech Stack
*   **Frontend**: React.js
*   **Styling**: Tailwind CSS
*   **Icons**: Lucide React
*   **State Management**: React Hooks (useState, useEffect)
